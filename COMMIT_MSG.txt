Rename the project from signatures to signature

Repo, custom domain and base URL all move. Everything under docs/ is
regenerated against the new host, so every asset URL in every style points at
signature.cyberskill.world.

The bare word "signatures" is left alone. It appears 41 times outside docs/
and only 18 of those were the project identifier - the rest are an English
plural, in "verifying generated signatures", "All signatures" and "Email
signatures", where the site genuinely holds more than one. A find-and-replace
would have turned those into broken sentences, so the two identifiers were
renamed by hand:

  signatures.cyberskill.world    -> signature.cyberskill.world
  cyberskill-official/signatures -> cyberskill-official/signature

Plus two the URL replace could not see - `cd signatures` after a clone that
now produces a `signature` directory, and the tree in README's repository
layout - and one identifier hiding among the plurals, the signatures-bot
User-Agent in issue_to_record.py.

Anything already installed against the old host keeps working only as long as
signatures.cyberskill.world resolves. At the time of this change that was one
test paste, so nothing real breaks; if that stops being true, the old
hostname has to keep resolving rather than be retired.

316 tests pass. docs/ rebuilt clean.
