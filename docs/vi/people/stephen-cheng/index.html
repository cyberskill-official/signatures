Dán vào Gmail

  1. Nhấn Verify & copy ở trên.
  2. Gmail → Cài đặt (biểu tượng bánh răng, góc trên bên phải) → Xem tất cả cài đặt → Chung.
  3. Cuộn xuống mục Chữ ký. Tạo mới nếu bạn chưa có.
  4. Bấm vào ô và dán bằng Cmd/Ctrl+V.
  5. Đặt làm mặc định cho thư mới và thư trả lời nếu bạn muốn dùng ở mọi nơi.
  6. Lưu thay đổi ở cuối trang - rất dễ bỏ sót.
