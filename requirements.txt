# This is not pedantry. Different Pillow versions encode identical pixels to
# different PNG bytes, which changed every asset's ?v= content hash and showed
# up as a diff on unrelated builds. make_assets.py now skips writes when the
# pixels match, but pinning fixes the cause rather than the symptom.
#

# full render suite before anyone accepts them.
